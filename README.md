## 🚀 Featured Projects & Currently Working On

- 🌾 **EcoPack-AI (AI-Powered Sustainable Packaging System)**  
  Building an ML-driven recommendation system using **XGBoost** and **Random Forest** to predict material cost, CO₂ impact, and suitability scores. Includes PostgreSQL database integration, dynamic multi-attribute ranking logic, and interactive Plotly BI analytics.  
  🔗 [Live App](https://ecopackailk.vercel.app) | 💻 [Repository](https://github.com/anii-123/EcoPackwithAI)

- 📊 **Amazon Prime Video Content Analytics Dashboard**  
  Engineered an interactive **Power BI** dashboard conducting end-to-end exploratory analysis of content distribution, genre density, country-specific production (USA, India), and content growth velocity post-2015 using DAX and Power Query.  
  💻 [Repository](https://github.com/anii-123/Amazon-Prime-Video-PowerBI-Dashboard)

- ⚡ **Productivity-WFH (Remote Worker Productivity Predictor)**  
  Developed a **Flask** web application integrated with **Scikit-Learn** predictive models to evaluate remote worker productivity metrics based on environmental and activity features.  
  🔗 [Live App](https://productivity-wfh.vercel.app) | 💻 [Repository](https://github.com/anii-123/productivity-wfh)

- 📱 **FarmConnect (Smart Farmer Registration & Location Mobile App)**  
  Built a cross-platform **Flutter** application with a 3-step registration workflow, auto PIN code location detection via **India Post API**, SQLite offline database, and real-time **GPS distance calculation** to Kalmeshwar APMC Market using the Haversine formula.  
  💻 [Repository](https://github.com/anii-123/farmconnect)

- 🧩 **Data Structures & Algorithms Repository**  
  Solves 100+ LeetCode problems in **Java**, focusing on optimized time and space complexity analysis across Arrays, Graphs, Trees, and Dynamic Programming.  
  💻 [Repository](https://github.com/anii-123/leetcode_coding)
